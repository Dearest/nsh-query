# Security

## Reporting a vulnerability

Report it privately through GitHub: [open a security advisory](https://github.com/Dearest/nsh-query/security/advisories/new) on this repository. Do not open a public issue.

Say what is affected, how to reproduce it (a fixture or a few lines of an app), and the nsh-query and NSH versions. The maintainers answer within 7 days, agree on a fix and a disclosure date with you, and credit you in the advisory unless you prefer not.

A vulnerability in query-core itself (`vendor/`) is TanStack Query's: report it to [TanStack/query](https://github.com/TanStack/query/security) as well. nsh-query picks up the fix with the next query-core upgrade.

## Supported versions

Only the latest release gets fixes while nsh-query is at 0.x.
